# Recursive Productive Capacity

Fei Yang, 14 October 2026. Working manuscript v1.0.0 for scholarly discussion.

**Recursive Productive Capacity: An Intergenerational Evidence Framework for Autonomous Machine Economies** is a conceptual and methodological proposal for assessing joint productive services through at least two renewal events under one admissible, observation-adapted policy.

## Status and scope

The supplied source package describes this version as a journal-neutral final submission candidate and calls for named-author review before formal submission. No journal submission, acceptance, institutional endorsement or independent human peer review is claimed here.

The paper proposes a measurement and evidence contract. Its components draw on established economic, viability, dynamic programming and formal verification methods. All numerical examples and production schedules are synthetic. The 47 supplied checks concern declared finite models and arithmetic. No industrial self-reproduction, new growth theorem, new stochastic-control algorithm, or superiority over an equally informed dynamic optimizer is established. The practical incremental value remains to be tested.
